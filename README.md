# North American Mortgage Decision Lab

Six Canadian mortgage calculators in one page (payment and debt service, down payment, rate sensitivity, renewal, rent vs buy, prepayment) with charts, share links and PDF export.

Live: https://alenzacodes.github.io/mortgage-decision-lab/

## How to use

Open the live page, or clone the repo and open index.html in a browser. No build step and no install. Change the inputs and the results update as you go.

Run the tests with Node:

    node tests/test.js
